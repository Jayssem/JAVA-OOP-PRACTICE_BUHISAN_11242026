This file contains the complete Java code for three practice activities: Campus Printing Account (PrintAccount), Lab Grade Record (LabGrade), and Campus Wallet Transfer (CampusWallet). Each activity has two classes one class that keeps its data private and uses methods to check rules before changing values, and a Main class that creates two separate objects to test the code and print the results. The required Q&A answers and extra test notes are also included inside the code as //comments.
